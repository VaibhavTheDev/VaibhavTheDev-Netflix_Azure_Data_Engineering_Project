# Netflix Azure Data Engineering Project

## 📌 Project Overview

This project focuses on building an end-to-end Azure Data Engineering solution using Microsoft Azure services and Apache Spark technologies. The objective is to ingest, store, process, transform, and organize raw data into structured, analytics-ready datasets.

The project uses Azure Data Factory for data orchestration, Azure Data Lake Storage Gen2 for data storage, and Azure Databricks with PySpark for large-scale data processing. Delta Lake and Unity Catalog are used as part of the data management and lakehouse architecture.

## 🎯 Project Objectives

- Build an end-to-end cloud-based data engineering pipeline.
- Ingest and organize raw datasets using Azure Data Factory.
- Store raw and processed data in Azure Data Lake Storage Gen2.
- Perform data cleaning and transformation using Azure Databricks and PySpark.
- Implement scalable data processing using Apache Spark.
- Manage structured datasets using Delta Lake.
- Organize and govern data assets using Unity Catalog.

## 🏗️ Project Architecture

The project follows an Azure-based data engineering workflow:

1. **Data Ingestion:** Azure Data Factory is used to ingest source data.
2. **Data Storage:** Raw datasets are stored in Azure Data Lake Storage Gen2.
3. **Data Processing:** Azure Databricks and PySpark are used to clean and transform the data.
4. **Data Management:** Delta Lake is used to manage processed datasets.
5. **Data Governance:** Unity Catalog is used to organize and govern data assets.
